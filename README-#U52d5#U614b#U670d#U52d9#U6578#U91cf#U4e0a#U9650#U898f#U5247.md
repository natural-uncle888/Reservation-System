# 動態服務數量上限規則

本版將原本單一「最大可填數量」改為三種規則：

1. **固定上限**：沿用原本最大數量，例如最多 10 台。
2. **跟隨冷氣清洗台數**：前台最大可選數量自動等於本筆預約的冷氣清洗台數，適合風鼓拆洗、室外機沖洗等 1:1 冷氣加購。
3. **不限制**：前台不顯示固定上限；系統安全上限仍為單次 99。

## 相容性

舊的動態服務設定若沒有 `quantity_limit_type`，會自動視為 `fixed`，原有 `max_quantity` 繼續有效。

## 前後端驗證

- 前台會依規則限制數量並顯示提示。
- 若選「跟隨冷氣清洗台數」，會讀取本筆預約冷氣台數，例如 4 台冷氣即最多 4 台加購。
- 送出時 Netlify Function 會重新讀取後台服務設定進行第二次驗證，避免只靠前端限制。
- 若服務設定暫時無法讀取，為避免影響既有接單流程，會保留原本送出機制。
